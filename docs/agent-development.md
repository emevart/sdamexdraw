# Работа Claude Code и Codex

Обновлено: 2026-09-09.

## Адаптеры и проверки

AGENTS.md — общий слой; CLAUDE.md импортирует соседний AGENTS.md. Codex-адаптеры .agents/skills/ читают единое тело .claude/skills/. Slash-команды Claude не считаются автоматически доступными в Codex.

Hooks из .claude/settings.json работают только в Claude и используют текущий CLAUDE_PROJECT_DIR. Autofix использует локальный ESLint, не скачивает пакеты. Отсутствие зависимости означает непройденную автоматическую проверку. Codex самостоятельно соблюдает gates AGENTS.md. Bash hooks даже в Claude не перехватывают все способы записи/API и не заменяют CI.

Команды — в AGENTS.md и package.json/CI. Для Markdown достаточно diff, ссылок, импортов и формата изменённых файлов; не нужны установка Yarn, сборка демо и перезапуск потребителя. Для hooks дополнительно Bash syntax и scripts/test-agent-hooks.sh (Git Bash и jq, временный fixture).

Для кода нужны lint/typecheck, релевантные unit-тесты и сборка пакета. При общем падающем suite сравни ту же команду на базе и запиши различия. Визуальная проверка — e2e/AGENTS.md; сохраняй viewport, target, SHA.

## Контракт с SdamEx

Проверяй публичные типы/CSS exports, старые сцены, undo/redo, RU/EN hotkeys, freedraw/highlighter и touch в затронутых сценариях. Сборка форка сама по себе не проверяет TypeScript-потребителя.

Для установки нужен отдельный checkout потребителя, его AGENTS.md, фиксированная версия артефакта и integrity. Обновляются package.json и lockfile, выполняются его gates. dist должен происходить от проверенного release SHA. Уже выданный URL версии не перезаписывается.

## Коллеги и находки

Координатор распределяет независимые задачи по сессиям/checkout с ownership. Subagents решают узкие внутренние задачи. Общие файлы и выпуск интегрирует один владелец. Состояние задачи хранится по шаблону checkpoint.

Побочная находка: вопрос/гипотеза/дефект/предложение, ссылка на evidence, достоверность, влияние/зависимость, владелец следующей проверки. После проверки: принято в backlog/задачу, отложено с условием возврата либо отклонено с причиной. Дубликаты объединяются. Важные решения и дизайн — пользователю в чате; находка не разрешает внешнюю публикацию или расширение scope.
