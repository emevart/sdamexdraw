# Changelog

Все заметные изменения в SdamExDraw документируются здесь.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Версионирование: [Semantic Versioning](https://semver.org/).

## [0.28.7] - 2026-07-14

### Исправлено

- В compact desktop toolbar подсказка под панелью временно скрывается, пока открыт picker выбора `selection`/`lasso`, и возвращается после его закрытия

## [0.26.72] - 2026-03-20

### Откачено

- Revert: увеличение порога замыкания 30→50px и overlap-хак (визуально добавляли лишнюю линию)

## [0.26.69] - 2026-03-20

### Исправлено

- Умное сглаживание: per-segment решение — прямые рёбра спрямляются, кривые сглаживаются (deviation check на каждом сегменте)

## [0.26.68] - 2026-03-20

### Исправлено

- Умное сглаживание: фильтр плотности углов — если >30% точек "углы", считать кривой и сглаживать

## [0.26.67] - 2026-03-20

### Исправлено

- Иконка миникарты: активное состояние светлее (primary-light вместо primary)
- Полигоны: рёбра между углами спрямляются (проекция на прямую) вместо сглаживания
- Transform после спрямления: нормализация точек + обновление x/y предотвращает обрезание при уменьшении

## [0.26.66] - 2026-03-20

### Добавлено

- Умное сглаживание (hold-to-straighten): детекция углов, сглаживание по сегментам, сохранение вершин
- Автозамыкание freedraw: почти замкнутые фигуры (gap < 30px) стягиваются ease-out методом
- Transform после спрямления: Procreate-style поворот/масштаб не отпуская палец
- Snap-to-first магнетизм: линии замыкаются в полигон при приближении к первой точке (20px порог)
- Визуальный индикатор замыкания на первой точке линии

### Исправлено

- Иконка миникарты: заменена с пейзажа на сложенную карту

## [0.26.65] - 2026-03-20

### Добавлено

- Upstream: text auto-resize handle — ручка сброса auto-resize справа от текстового блока
- Upstream: вертикальное центрирование текста по курсору при создании
- Upstream: привязка текста к сетке при создании (когда grid snap включён)
- Upstream: валидация double-click по позиции и дистанции
- Upstream: оптимизация `pointRotateRads` — ранний возврат при angle=0
- Upstream: `Range` компонент рефакторинг в универсальный слайдер
- Upstream: `getActiveTextElement` утилита для получения активного текстового элемента
- Upstream: тип `editingTextElement` сужен до `ExcalidrawTextElement`

## [0.26.64] - 2026-03-19

### Исправлено

- Сглаживание кривых: уменьшен радиус smoothing 8→3 для минимизации сжатия дуг

## [0.26.63] - 2026-03-19

### Исправлено

- Спрямление прямых линий: сохраняет все точки (проекция) вместо 2 финальных — рендерер не сужает штрих

## [0.26.62] - 2026-03-19

### Исправлено

- Спрямление кривых: moving average сглаживание вместо RDP simplification — сохраняет форму и длину кривой
- Спрямление прямых: проекция на линию start→end

## [0.26.61] - 2026-03-19

### Исправлено

- Спрямление: линия больше не сжимается — проекция на прямую вместо arc length parameterization

## [0.26.60] - 2026-03-19

### Исправлено

- Спрямление: сброс состояния после анимации (повторные штрихи не блокируются)
- Спрямление: конец линии остаётся под курсором (не добавляется лишняя точка при pointerUp)
- Миникарта: кнопка переключения слева от зума в одном ряду
- Миникарта: точный рендеринг фигур вместо прямоугольников (freedraw, линии, эллипсы, ромбы)

## [0.26.59] - 2026-03-19

### Добавлено

- Спрямление линии (hold-to-straighten): удержание карандаша без движения 500мс спрямляет штрих (прямая или RDP-сглаженная кривая) с анимацией
- Drag & drop картинки из карточки задания на доску (`text/uri-list` URL → fetch → insert)
- Миникарта навигации: переключаемая мини-карта рядом с зумом, клик/drag для перемещения по канвасу

## [0.26.58] - 2026-03-19

### Добавлено

- `history.undo()` и `history.redo()` в ExcalidrawImperativeAPI для программного вызова из внешних тулбаров

## [0.26.57] - 2026-03-19

### Добавлено

- Двухуровневый мобильный тулбар: компактный нижний ряд (категории) + верхний ряд настроек с вариантами инструментов
- Все варианты фигур, линий, карандаша/маркера, выделения доступны в settings row с горизонтальным скроллом
- Фигуры отсортированы по категориям: базовые → четырёхугольники → многоугольники | призмы → пирамиды → тела вращения
- Тонкий скроллбар на десктопе при узких экранах (`@media (pointer: fine)`)

### Изменено

- Убраны ToolPopover дропдауны для фигур, линий, карандаша — заменены плоскими кнопками в settings row
- Settings row: цвета + кнопка свойств (⚙) + варианты инструментов inline

### Исправлено

- Позиционирование поповеров привязано к тулбар-контейнеру через Popover.Anchor virtualRef
- Перекрытие дропдаунов с панелью shape actions на мобилке
- PropertiesPopover открывается вверх на мобилке (не перекрывает тулбар)
- Z-index ToolPopover и extra tools dropdown поднят до ui-styles-popup
